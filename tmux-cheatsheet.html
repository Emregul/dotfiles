🪟 tmux Cheatsheet

Catppuccin Mocha · prefix = Ctrl+Space · vi-mode copy · TPM plugins · seamless nvim splits

🗂 Sessions
Switch / Create
prefixCtrl+j
fzf session switcher popup
prefixCtrl+t
zoxide project opener — jump into a recent dir as a new session
prefixs
Session/window tree picker (built-in)
prefixS
New session (prompts for name)
prefix$
Rename current session
prefix(
Previous session
prefix)
Next session
prefixL
Last (most-recent) session
prefixd
Detach from session (keeps running)
detach-on-destroy=off → killing a session jumps to another, never kicks you out of tmux
🪟 Windows
Create / Close
prefixc
New window (opens in current pane's directory)
prefix&
Kill current window
prefix,
Rename window
Switch
prefixn
Next window
prefixp
Previous window
prefix1…9
Jump to window #
prefixl
Last (most-recent) window
prefixw
Window picker (tree)
Reorder
Ctrl+Shift+←
Move window left (no prefix needed)
Ctrl+Shift+→
Move window right (no prefix needed)
prefix.
Move window to a different index
Windows start at 1 and renumber automatically when one is closed
▦ Panes — Create & Close
prefix|
Split horizontal (vertical bar) — opens in current dir
prefix-
Split vertical — opens in current dir
prefixx
Kill current pane (with confirm)
prefix!
Break pane into a new window
prefixz
Zoom toggle (built-in)
prefixm
Maximize toggle (custom — repeatable)
prefixq
Show pane numbers (press # to jump)
prefixSpace
Cycle pane layouts
prefix{ / }
Swap pane with previous/next
↔ Panes — Resize
prefixH
Resize left 5 (repeatable — keep tapping H)
prefixJ
Resize down 5 (repeatable)
prefixK
Resize up 5 (repeatable)
prefixL
Resize right 5 (repeatable)
After prefix+H, you can keep pressing H/J/K/L without re-pressing prefix (-r flag)
🧭 Pane Navigation (smart-splits)
Ctrl+h
Move left — works across tmux ↔ nvim seamlessly
Ctrl+j
Move down
Ctrl+k
Move up
Ctrl+l
Move right
Built-in fallbacks
prefixo
Cycle to next pane
prefix;
Toggle to last pane
prefix↑/↓/←/→
Move by arrow direction
No prefix needed for Ctrl+hjkl — same keys move between nvim splits and tmux panes
📋 Copy Mode (vi)
prefix[
Enter copy mode — scroll & select
prefix]
Paste from tmux buffer
In Copy Mode
h j k l
Move cursor (vi keys)
w / b
Word forward / back
g / G
Top / bottom of buffer
Ctrl+u / Ctrl+d
Half page up / down
/ / ?
Search forward / backward
n / N
Next / previous search match
v
Begin selection
V
Line selection
Ctrl+v
Block selection
y
Yank → pbcopy (system clipboard) and exit
q / Esc
Exit copy mode
Mouse drag also selects + copies. OSC52 propagates clipboard through SSH.
⚡ Quick Copy (plugins)
tmux-thumbs (hint-based)
prefixF
Highlight matches — paths, hashes, URLs, IPs. Press the hint letters to copy.
extrakto (fuzzy)
prefixe
Fuzzy-pick any word/path/URL from the current pane
↳ Tab
Toggle filter mode (word / line / path / url)
↳ Enter
Insert into current command line
↳ Ctrl+y
Copy to system clipboard
↳ Ctrl+e
Open in $EDITOR
Thumbs = fastest for visible single token. Extrakto = best for searching scrollback.
🔌 TPM & Resurrect
Plugin Manager (TPM)
prefixI
Install plugins from ~/.config/tmux/tmux.conf
prefixU
Update plugins
prefixAlt+u
Uninstall plugins removed from config
Resurrect / Continuum
prefixCtrl+s
Save all sessions/windows/panes (incl. nvim sessions)
prefixCtrl+r
Restore last saved state
continuum auto-saves every 15 min and auto-restores at tmux start
⌨ Shell Commands
Sessions
tmux
Start new session (auto-launched by WezTerm)
tmux ls
List running sessions
tmux a
Attach to last session
tmux a -t name
Attach to named session
tmux new -s name
New named session
tmux kill-session -t name
Kill named session
tmux kill-server
Kill all sessions (full restart)
Inside tmux
prefix:
tmux command prompt (e.g. :set-window-option …)
prefix?
List all keybindings
⚙ Misc & Config
prefixCtrl+y
Toggle sync-panes — type in one pane, runs in all
prefixr
Reload tmux.conf
prefixCtrl+Space
Send literal Ctrl+Space to app (double-tap prefix)
prefixt
Show big clock in pane
Settings in your config
mouse
Enabled — drag to resize, scroll to enter copy mode
monitor-activity
Highlight windows with new output (no bell/flash)
automatic-rename
Windows named after current directory
history-limit
50 000 lines per pane
escape-time
0 ms — instant Esc in nvim
focus-events
On — nvim autoread works
aggressive-resize
Resize to active client only
set-clipboard
OSC52 — copy works through SSH
Edit ~/.config/tmux/tmux.conf and prefix+r to apply without restarting
